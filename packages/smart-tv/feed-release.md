The latest AIOStreams TV apps. See the [TV apps README](https://github.com/Viren070/AIOStreams/tree/main/packages/smart-tv#install) for how to install them.

### LG (webOS)

[aiostreams-webos.ipk](@BASE@/aiostreams-webos.ipk), for Developer Mode. With the Homebrew Channel, add `@REPOSITORY@` as a repository in its settings instead: the app then installs and updates from the TV.

### Samsung (Tizen)

[aiostreams-tizen.wgt](@BASE@/aiostreams-tizen.wgt), unsigned: the installer signs it for your TV.
