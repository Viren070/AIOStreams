Your configuration's [media server](/guides/media-server) speaks the same API as Jellyfin, so Jellyfin apps can sign in to it like any other Jellyfin server. You don't need Jellyfin itself: the server runs on your AIOStreams instance.

Swiftfin, Findroid, Streamyfin, Jellyfin for Android TV, Jellyfin for Kodi and Infuse all work. In a browser, and on Windows, Mac and Linux, use the [AIOStreams app](/guides/app) instead: it is built for this server.

<Callout type="info">
  Streams are **played directly**, never transcoded. Your app has to be able to
  play the file as it is, so a device that struggles with a format in other apps
  will struggle here too. Picking another version usually helps. Only streams
  with a link play, so P2P torrents are left out; use debrid or Usenet.
</Callout>

## Connecting an app

Everything an app needs is on the configure page, under **Save & Install → Jellyfin apps → Connect**. There are three ways in:

| Way                                                                       | Use it for                                     | What you enter                                    |
| ------------------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------- |
| **Address with a sign-in picker** (best)                                  | Your own devices and your household's          | Pick a user, then the password                    |
| [Quick Connect](#on-a-tv-quick-connect)                                   | TVs and anything you type on with a remote     | Nothing; you approve a code on the configure page |
| [A user's own address](/guides/media-server#users-outside-your-household) | Someone outside your household                 | Their PIN, or Quick Connect                       |
| [Server address](#using-the-plain-server-address)                         | A device you'd rather not give the picker link | Your UUID or alias, then the password             |

The sign-in picker is the easiest: the app lists your configuration's users on its sign-in screen, the way a normal Jellyfin server does, so nobody types a UUID.

<Steps>

<Step>

### Add the server

In your app, add a server and paste the **Address with a sign-in picker** from the Connect tab.

If your configuration has a share alias in its [profile](/guides/config-profiles), the address is short, `https://your-instance/jellyfin/u/<alias>`, so you can type it on a TV. Without one it holds your UUID and an encrypted password, and is easier to paste than to type.

</Step>

<Step>

### Pick a user

The app lists the [users](/guides/media-server#users-and-pins) of your configuration: the primary user, which is your configuration itself, and any household users you added. Pick one.

</Step>

<Step>

### Enter the password

Enter your configuration password. If that user has a [PIN](/guides/media-server#pins), add it after the password with a `/`, for example `yourpassword/1234`.

If the instance allows it, a user with a PIN of 6 or more digits can [enter just their PIN](/guides/media-server#letting-people-sign-in-with-only-their-pin) instead.

</Step>

</Steps>

<Callout type="warn">
  The picker address contains the same secret as your Stremio install links.
  Treat it like one of them and only put it on devices in your household.
</Callout>

A user left off the picker can still sign in: choose the app's option to sign in manually and type their name, just the name. A user kept [separate from the others](/guides/media-server#users-outside-your-household) has an address of their own instead.

### On a TV: Quick Connect

Typing with a remote is painful, so use **Quick Connect** instead:

1. Add the server to the TV app as above, then choose **Quick Connect** on its sign-in screen. It shows a six-digit code.
2. Type the code into the **Quick Connect** box on the Connect tab. The device waiting on it appears.
3. If you have household users, choose who to sign in as, and enter their PIN if they have one. Then press **Approve**.

An app that is already signed in may also offer a Quick Connect screen of its own. Approving a code there signs the new device in as the same user.

### Using the plain server address

The **Server address** on the Connect tab has no secret in it. It is your instance's address followed by `/jellyfin`, for example `https://aiostreams.example.com/jellyfin`. Apps show no user list on it, so you type who you are:

- **Username**: the one shown on the Connect tab. That is your configuration UUID, or its alias if you gave it one through a [profile](/guides/config-profiles). To sign in as a household user, add `/` and their name, for example `<uuid>/Sam`.
- **Password**: your configuration password, with `/PIN` added for a user with a PIN, as above.

### What to type, at a glance

| Signing in as               | On the sign-in picker address                                                                         | On the server address            |
| --------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------- |
| The primary user            | Pick it; your password                                                                                | `<uuid>` or alias; your password |
| A household user            | Pick them; your password                                                                              | `<uuid>/<name>`; your password   |
| Either, with a PIN          | `yourpassword/PIN`                                                                                    | `yourpassword/PIN`               |
| A household user, PIN alone | The PIN, [if the instance allows it](/guides/media-server#letting-people-sign-in-with-only-their-pin) | Not possible                     |

## App differences

Jellyfin apps each use a different part of the server, so a few things vary:

- **Collections.** Some apps, such as Plezy and Jellyfin for Kodi, only show the first Collections library. Put the one you use most first in your catalog order. Plezy also shows collections in a library's Collections tab rather than as a library of their own, and draws every collection as a portrait poster, cropping wide artwork.
- **Version picker.** Every app shows versions differently. Some list them on the item page, some only when you press play, and some only in the player.
