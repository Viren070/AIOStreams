# AIOStreams-Friends

A small personal fork of [AIOStreams](https://github.com/Viren070/AIOStreams) that adds an in-browser MKV player and SyncPlay so I can watch with friends. It stays up to date with upstream.

For everything about AIOStreams itself (features, setup, configuration), see the [original README](https://github.com/Viren070/AIOStreams#readme).

## Plan

- **In-browser MKV player:** use [movi-player](https://moviplayer.com/) in the web client, so MKVs, AC3/DTS/TrueHD audio and embedded subtitles play in the browser without server transcoding.
- **SyncPlay:** add watch parties so friends can stay in sync on play, pause and seek. The design isn't settled yet.

## Changes from upstream

None yet.
